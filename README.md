# Егор / 18 — сайт-приглашение

Адаптивный лендинг на **Vue 3 + Vite** по приглашению на 5–6 декабря **2026** года. Локальный шрифт Holodilnik, оригинальное фото, оформление бумажного билета и чёрно-белая палитра. Все шрифты и изображения находятся в проекте; внешние сервисы используются только по нажатию на ссылки.

## Запуск через Docker Compose

Нужен запущенный Docker Desktop или Docker Engine с Compose.

```sh
docker compose up --build -d
```

Открыть **http://localhost:80** (если `PORT` не переопределён). Контейнер собирает Vue-приложение и отдаёт готовый сайт через Nginx. Healthcheck проверяет доступность страницы.

Для другого порта:

```sh
PORT=3000 docker compose up --build -d
```

Остановка:

```sh
docker compose down
```

Для просмотра с телефона в той же Wi-Fi сети открой `http://<локальный-IP-компьютера>:80` (или выбранный `PORT`). Для публичного сайта понадобится домен и HTTPS через обратный прокси.

## HTTPS на сервере

Готовый запуск с Caddy и автоматическим сертификатом для `ea.csweekly.ru` находится в `compose.https.yaml`. Подробная инструкция переключения с текущего HTTP-запуска, проверки сертификата и диагностики превью Telegram — в [HTTPS.md](HTTPS.md).

После первоначальной настройки обновляй HTTPS-версию так:

```sh
docker compose -f compose.https.yaml up --build -d
```

HTTPS-файл самостоятельный; его не нужно объединять с `compose.yaml`.

## Изменение информации

- `src/event.js` — дата, год, адрес, программа и ссылки на поезда.
- `src/App.vue` — текст и структура лендинга.
- `src/style.css` — адаптация, дизайн и анимации.
- `public/images/poster.png` — исходное изображение; портрет выделен через CSS без изменения исходника.
- `public/images/hyundai-staria.png` — предоставленное фото Hyundai Staria в блоке трансфера.
- `organizer` в `src/event.js` — контакт Telegram: ссылка есть в блоке связи, в подвале и в событии календаря.
- `public/fonts/Holodilnik.otf` — предоставленный шрифт.

После изменения даты, года или программы проверь соответствующий текст в `src/App.vue` и `index.html`. Основные данные календаря берутся из `src/event.js`; файл `public/egor-18.ics` автоматически создаётся при запуске разработки и при сборке.

## Превью ссылки в Telegram

В исходном HTML страницы есть Open Graph и метаданные для больших карточек: оригинальный постер `public/images/poster.png`, заголовок «Егору Аксёнову — 18! Ты приглашён» и подпись с датой, городом, программой и трансфером. Telegram получает их без запуска Vue и JavaScript. Стандарт метаданных: [Open Graph](https://ogp.me/).

В HTTPS-конфигурации адрес страницы — `https://ea.csweekly.ru/`, а постера — `https://ea.csweekly.ru/images/poster.png`. Обычный HTTP-файл `compose.yaml` по умолчанию собирает метаданные для `http://31.57.93.209/`; значение можно изменить через `SITE_URL`. Прямая сборка Vite без настройки использует `https://ea.csweekly.ru/`.

Если домен изменится, задай новый адрес при сборке:

```sh
SITE_URL=https://your-domain.ru docker compose up --build -d
```

Или скопируй `.env.example` в `.env` и измени `SITE_URL` перед сборкой. После изменения домена пересобери Docker-контейнер или папку `dist`.

Telegram должен иметь доступ к публичной странице и `/images/poster.png`. Ссылка на localhost или компьютер в локальной сети не даёт Telegram доступ к сайту. Фактическое превью можно проверить после публикации, вставив публичную ссылку в поле сообщения Telegram; отправлять сообщение для этой проверки не нужно. Вид и размер карточки зависят от клиента Telegram и его настроек превью.

## Календарь на iPhone и Android

Кнопка «Сохранить дату» открывает выбор календаря:

- **Открыть Apple Calendar** — ссылка `webcal://<текущий-домен>/egor-18.ics` вызывает приложение календаря на iPhone, iPad и Mac и предлагает подписаться на календарь праздника. Подписку подтверждает пользователь; запуск приложения зависит от браузера и настроек устройства. Домен и порт берутся из текущего адреса страницы. Для проверки с телефона сайт должен быть доступен по этому адресу, а для публичной подписки — из интернета.
- **Google Calendar** — открывает заполненную форму события для Android и браузеров. Пользователь подтверждает сохранение и настройки уведомления.
- **Скачать файл события** — запасной способ добавить одно событие через .ics: 5 декабря 18:00 — 6 декабря 11:00 по Москве, с программой, адресом и напоминанием за сутки (`VALARM`). Nginx отдаёт файл с типом `text/calendar`. На iPhone можно открыть .ics как вложение через Apple Mail. На публичном сайте используй HTTPS.

Сайт не может гарантированно вызвать системный диалог или записать задачу напрямую в отдельное приложение «Напоминания» на любом телефоне. Здесь реализовано событие календаря с уведомлением; его сохранение подтверждает пользователь. Настройки уведомления могут зависеть от календаря.

## Программа и билеты

Время поездов перенесено из изображения и не является подтверждением актуального расписания. Ссылки ведут на реальные страницы маршрутов Туту; пользователь выбирает 5 декабря для поездки туда и 6 декабря для возвращения. Цены и номера поездов не выдуманы и не указаны.

В исходнике дорога до дома обозначена как 22:00–23:30, а тусовка — с 22:30. Это сохранено с пояснением о необходимости уточнить точное время сбора. Трансфер — минивэн Hyundai; место посадки и вместимость не указаны, поскольку организатор их не предоставил.

## Анимации и доступность

Появление элементов при прокрутке, наклон билета мышью, печать-штамп, сканирование штрихкода, бегущая строка, обратный отсчёт, переключение дней, эквалайзер, минивэн на дороге, раскрытие деталей и конфетти при нажатии на «18». Кнопка у бегущей строки останавливает декоративные анимации. Учитывается `prefers-reduced-motion`, поддерживаются клавиатура, видимый фокус и нативный диалог выбора календаря.
