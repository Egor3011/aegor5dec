# Егор / 18 — сайт-приглашение

Адаптивный лендинг на **Vue 3 + Vite** по приглашению на 5–6 декабря **2026** года. Локальный шрифт Holodilnik, оригинальное фото, оформление бумажного билета и чёрно-белая палитра. Все шрифты и изображения находятся в проекте; внешние сервисы используются только по нажатию на ссылки.

## Запуск через Docker Compose

Нужен запущенный Docker Desktop или Docker Engine с Compose.

```sh
docker compose up --build -d
```

Открыть **http://localhost:8080**. Контейнер собирает Vue-приложение и отдаёт готовый сайт через Nginx. Healthcheck проверяет доступность страницы.

Для другого порта:

```sh
PORT=3000 docker compose up --build -d
```

Остановка:

```sh
docker compose down
```

Для просмотра с телефона в той же Wi-Fi сети открой `http://<локальный-IP-компьютера>:8080`. Для публичного сайта понадобится домен и HTTPS через обратный прокси.

## Разработка без Docker

Node.js 22.12+.

```sh
npm ci
npm run dev
```

Проверка и production-сборка:

```sh
npm test
npm run build
```

## Изменение информации

- `src/event.js` — дата, год, адрес, программа и ссылки на поезда.
- `src/App.vue` — текст и структура лендинга.
- `src/style.css` — адаптация, дизайн и анимации.
- `public/images/poster.png` — исходное изображение; портрет выделен через CSS без изменения исходника.
- `public/images/hyundai-staria.png` — предоставленное фото Hyundai Staria в блоке трансфера.
- `organizer` в `src/event.js` — контакт Telegram: ссылка есть в блоке связи, в подвале и в событии календаря.
- `public/fonts/Holodilnik.otf` — предоставленный шрифт.

После изменения даты, года или программы проверь соответствующий текст в `src/App.vue` и `index.html`. Основные данные календаря берутся из `src/event.js`; файл `public/egor-18.ics` автоматически создаётся при запуске разработки и при сборке.

## Календарь на iPhone и Android

Кнопка «Сохранить дату» открывает выбор календаря:

- **Apple Calendar / .ics** — событие 5 декабря 18:00 — 6 декабря 11:00 по Москве, с программой, адресом и напоминанием за сутки (`VALARM`). Nginx отдаёт файл с типом `text/calendar`. В зависимости от браузера и ОС файл откроется в календаре или скачается для импорта. На iPhone можно открыть .ics как вложение через Apple Mail. На публичном сайте используй HTTPS.
- **Google Calendar** — открывает заполненную форму события для Android и браузеров. Пользователь подтверждает сохранение и настройки уведомления.
- Отдельная ссылка позволяет скачать .ics вручную.

Сайт не может гарантированно вызвать системный диалог или записать задачу напрямую в отдельное приложение «Напоминания» на любом телефоне. Здесь реализовано событие календаря с уведомлением; его сохранение подтверждает пользователь. Настройки уведомления могут зависеть от календаря.

## Программа и билеты

Время поездов перенесено из изображения и не является подтверждением актуального расписания. Ссылки ведут на реальные страницы маршрутов Туту; пользователь выбирает 5 декабря для поездки туда и 6 декабря для возвращения. Цены и номера поездов не выдуманы и не указаны.

В исходнике дорога до дома обозначена как 22:00–23:30, а тусовка — с 22:30. Это сохранено с пояснением о необходимости уточнить точное время сбора. Трансфер — минивэн Hyundai; место посадки и вместимость не указаны, поскольку организатор их не предоставил.

## Анимации и доступность

Появление элементов при прокрутке, наклон билета мышью, печать-штамп, сканирование штрихкода, бегущая строка, обратный отсчёт, переключение дней, эквалайзер, минивэн на дороге, раскрытие деталей и конфетти при нажатии на «18». Кнопка у бегущей строки останавливает декоративные анимации. Учитывается `prefers-reduced-motion`, поддерживаются клавиатура, видимый фокус и нативный диалог выбора календаря.
